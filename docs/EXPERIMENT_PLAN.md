# 모델 개선 실험

## 아직 구현하지 않은 작업

기존 보고서의 모델 코드를 공통 입력·분할·평가 구조로 이식하는 작업부터 진행합니다. 각 HTML 보고서는 코드 자체가 아니므로 성능 수치를 그대로 재현된 결과로 옮기지 않습니다.

| 순서 | 실험 | 비교 대상 | 채택 판단 |
|---|---|---|---|
| E00 | Logistic Regression / LightGBM 기준 모델 | 같은 특징·분할·임계값 선택 절차 | 동일 평가 단위에서 복잡성 대비 이득 |
| E01 | 정상 전류-진동 관계의 잔차 특징 | E00 vs E00+잔차 | 정상 운전변화 FP 감소, Recall 유지 |
| E02 | 강한 이상 / 지속 이상 경보 | 단발 vs 연속 vs 두 경로 | 미탐지·오경보·실제 지연의 균형 |
| E03 | 진동·전류 별도 판단 | 통합 입력 vs 채널별 점수 | 전류 단독 이상을 지우지 않으면서 오류 조건 식별 |
| E04 | 정상 학습 보조 모델 | PCA / IF / AE | 추가 탐지 대비 추가 오경보와 운영 비용 |

### 잔차 특징

정상 학습 구간에서 전류 크기로 AI0/AI1 진동 크기를 각각 예측합니다. 실제-예상 진동을 추가 특징으로 사용합니다. 원래 특징은 유지합니다. 전류는 부하의 대리값이며 고장에도 변할 수 있습니다. 학습 범위 밖의 전류에서는 회귀 신뢰도를 별도 표시합니다. 전체 데이터에 회귀를 먼저 적합하지 않습니다.

### 경보

현재까지 확보한 표본만 사용합니다. 창의 마지막 표본 시각을 점수 이용 가능 시각으로 저장합니다. 신호 공백 뒤에는 연속 경보 이력을 초기화합니다. 1개 조각을 독립 고장 1건으로 부르지 않습니다. 실제 고장 시작 정보 없이 고장 전 조기탐지 시간을 주장하지 않습니다.

### 보조 모델

정상 이탈은 새로운 고장일 수도, 새로운 정상 운전조건일 수도 있습니다. 보조 경로 단독 반응은 관찰·확인 대상으로 평가합니다. 두 번째 보고서에 정상 학습 AE 경로가 이미 있으므로, E04는 아이디어의 최초 추가가 아니라 단순 모델과의 대체 비교입니다.
