# 공통 평가 규칙

## 데이터 한계

정상 2022-07-12와 이상 2022-07-17이 일치하므로 고장 효과와 날짜별 측정 조건을 분리할 수 없습니다. 날짜를 입력에서 빼는 것만으로 해결되지 않습니다. 현재 데이터의 재분할은 내부 비교이며 새 날짜 일반화 검증이 아닙니다.

## 기본 분할

각 파일에서 시각과 센서·라벨이 모두 같은 중복만 제거합니다. 같은 시각에 다른 값이 있거나 결측·비유한 수치·예상과 다른 라벨이 있으면 중단합니다. 빈 컬럼의 기존 CSV 인덱스는 특징으로 쓰지 않습니다.

시간 간격이 0.15초를 넘으면 새 기록 조각으로 나눕니다. 이 값은 센서 데이터의 공백 구분 설정이며 프레스 사이클 규칙이 아닙니다. 조각을 시간순으로 학습70%, 검증15%, 시험 나머지에 배정합니다. 정수 내림 때문에 실제 비율은 달라집니다. 원본 행부터 분할이 기록되고 모든 정리된 행이 정확히 한 조각에 포함됩니다.

이 기본 분할은 협업 출발점입니다. 짧은 이상 세션에서 나온 검증·시험이 매우 적으므로 한 번의 높은 점수만으로 최종 선정하지 않습니다. 추가 시간블록 검증에서 특징·증강·임계값의 선택은 평가 블록 밖에서 수행합니다. 간격을 둔 검증도 날짜 교란을 없애지는 않습니다.

## 평가 단위

- 창 단위: Precision, Recall, F1, AP(average precision), FP/FN.
- 조각 단위: 탐지된 이상 조각/평가 가능한 이상 조각, 오경보 정상 조각 비율.
- 커버리지: 전체 조각·행 수, 판정 가능/보류/제외 수와 정상·이상별 내역.
- 경보: 별개 경보 횟수, 확인 가능한 관측시간, 첫 점수 및 확정 경보의 실제 시각.
- 공백 구간은 관측한 정상 시간으로 임의 환산하지 않습니다.
- AP와 사다리꼴 적분 PR-AUC를 구분해 지표명을 적습니다.

실험 간 동일한 분할 manifest와 평가 모집단을 사용합니다. 창 길이에 따라 제외된 사례가 다르면 공통 대상 성능과 전체 커버리지를 함께 적습니다. 임계값 후보를 평가 데이터의 최댓값 등에서 가져오지 않습니다.

## 최종 선정

개발 데이터에서 목표 Recall 또는 허용 오경보를 미리 정하고 해당 조건의 실제 달성 여부를 보고합니다. 만족하는 후보가 없으면 실패를 기록하며 시험 결과를 보고 조건을 바꾸지 않습니다. 성능 차이가 작으면 단순한 모델을 우선합니다. 정상 점수나 p-value를 보정된 고장 확률로 부르지 않습니다.
